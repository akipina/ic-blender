Playing, editing and creating animations

Each clip in a creature's .sgm (Idle1, walk, Melee1 and so on) becomes a Blender Action. Edit it with Blender's tools; Export Model writes it back.

What import gives you: one Action per clip

With Clips as Actions on (default), each clip is an Action on the rig, with its own muted NLA track.

If you imported with that option off, press Clips to Actions.

Playing and scrubbing a clip

  1. Select the creature and pick a clip from Load Animation in the IC tab. The frame range and rate follow the clip.
  2. Press Space to play, or drag the Timeline playhead.
  3. Switch clips any time, there or in the Action Editor with the rig selected.

Editing a clip in the Dope Sheet or Graph Editor

The Actions belong to the rig, so select it first.

  1. Press Select Rig. Select the creature again when you want to edit geometry.
  2. Open a Dope Sheet in Action Editor mode, or the Graph Editor.
  3. In Pose Mode (Ctrl+Tab), go to a frame, pose a bone and key it with I. Auto Keying works too.

Exporting animations

  1. Select the creature and press Export Model. Save under a new name, not over the stock file.
  2. Read the report, for example clips: 9 kept, 1 written.

Only clips whose keys or names you change are rewritten. Rigs with active constraints or drivers rewrite every clip.

Creating a new clip

  1. Press Select Rig, enter Pose Mode, click New in the Action Editor and name the Action.
  2. Set the frame range (for example 1 to 21) and a frame rate of 30.
  3. Key the rest pose at the start, pose and key a middle frame, and key the rest pose at the end so it loops.
  4. Keep the Action active, select the creature and press Export Model. The clip takes the Action's name and frame range.

The game finds clips by name, so a new name plays only if the creature's blueprint uses it. To replace a stock clip, give yours the same name. To keep several new clips, use Push Down on each and mute its NLA track.

Renaming and deleting clips

  • Rename the Action, not the NLA track or strip, to rename the clip.
  • Delete a clip in the Outliner: Blender File > Actions > right-click > Delete.
  • Unlinking the Action or deleting its NLA track does not drop an imported clip.

Validate (will it load?) lists missing clips and export warnings before you write.

Rules the engine imposes (and the add-on follows)

  • A bone with no keys in a clip stays at rest under its parent.
  • One Action is one clip. NLA blending isn't exported; mute unmuted tracks to silence the warning.
  • Keys on a missing bone are left out, with a warning. Rename bones with Boner > Bones > Rename Bone, which updates Actions.
  • Actions left over from an earlier rig are ignored, with a warning.
