Getting started and the UI tour

IC Blender opens an Impossible Creatures creature (.sgm) as a patch model. The vertices you edit are the file's control points, and the surface you see is drawn from them. This chapter installs the add-on and tours it with the stock rhinoceros, rhinoceros.sgm.

Installing and launching

You need Blender 5.3.0 or newer.

  1. Open Edit > Preferences > Get Extensions, then the drop-down menu at the top right, Install from Disk.... Pick ic_blender-<version>.zip.
  2. Check that IC Blender is ticked under Add-ons. If your game is not in a usual Steam folder, set the Game folder in the add-on's preferences.
  3. In the 3D viewport press N and open the IC tab.
  • Uninstall the old SGM Native Patches add-on first.
  • A newer zip installs over an older one. If it then fails to load, uninstall it, restart Blender and install again.
  • Combine Preview ignores the Game folder setting. It looks at IC_INSTALL, then the usual Steam folders.
  • Stock creature files are not included: press Extract Stock Creatures in Combine Preview to copy them out of your game.
  • Intel Macs and ARM Windows get no ratings, cost or rank in Combine Preview.

Importing a stock creature

  1. Press IC Blender > Import Model, or use File > Import > Impossible Creatures Model (.sgm / .ebp). Pick rhinoceros.sgm. Leave Clips as Actions on to get each animation as a Blender Action.
  2. You can pick the .ebp instead. Only the model is imported; the motion tree, events and icon stay in the .ebp.
  3. Two objects appear: Rhinoceros (the control points) and Rhinoceros_rig (the armature).
  4. Frame the creature with View > Frame Selected (numpad .).

Gatherers, characters, structures and props use the same button and open as ordinary meshes; see their chapter.

What you are looking at

  • Control points: each vertex is one. A shared corner is a single vertex, so the surface stays closed.
  • Surface: a live textured overlay that follows your edits and the posed rig.
  • Control net: the 4x4 grid of every patch.
  • Rig: a Blender armature. Each control point belongs to one bone.
  • Clips: Actions on the rig. Edit, rename, add or delete them, and Export writes them.

The Display box:

  • Surface Only hides the control points and rig. Turn it off to edit.
  • Show Surface, Show Control Net: toggle the overlays.
  • Evaluated Surface: real geometry that renders in Eevee and Cycles. Editing is slower with it on.
  • Shading menu: Textured, By Limb, By Bone or Plain.
  • Surface Density: smoothness of the drawn surface.
  • Show Handle Dots: corners gold, handles blue.
  • Show Connections: highlights the rings where limbs attach.
  • Edit Opacity: surface opacity in Edit Mode.
  • Patch Rules (Max feel): a corner drags its handles, and interior points move automatically. Off means raw point editing.
  • Show Interior Points: unhides those points.
  • Lock Handles: a corner's other handles rotate with the one you move.
  • Live Checks: shows warnings while you work.
  1. Press Tab for Edit Mode. The panel adds the Modeling, Topology and Select boxes. A greyed-out button says why in its tooltip.
  2. Select a point and press G. Box and lasso select, proportional editing (O) and snapping work. X-Mirror Editing is on after import.
  3. Press 3 to select whole patches.

The IC panel, top to bottom

Below Display, a creature shows:

  • Name, control-point and patch counts, and X-Mirror Editing.
  • The rig box: Load Animation, the active Action and Select Rig.
  • Sculpt: see the sculpting chapter.
  • Tools: Attach, Symmetrize (X), Relax Seam Tangents, Retarget Creature to Mesh, Create Landmarks, Landmark Retarget, Trim Stray Surface, Validate (will it load?) and Combine Checks.
  • Bake Textured Mesh, Paint Skin, Transfer Texture, Edit UVs, Apply UVs (while a UV cage exists) and Export Model.
  • The Boner and Combine Preview sub-panels.

With an ordinary mesh active, Convert Mesh to Creature and Fit Patches to Mesh appear above Display.

Boner: Bones, Limbs, Connections

Boner has the tabs of Relic's Boner tool. With Follow Shading on (the link icon on the Bones tab), the Limbs and Bones tabs switch the shading to match.

  1. Limbs lists each limb's class, counts and status. A stub limb has no patches but lets other creatures' parts attach. Click a limb to classify, Rename or Delete it. In Edit Mode use Select Limb and Assign Selected to Limb.
  1. Bones: choose a Bone (or Pick Bone), rename it, or Add Bone under Active. In Edit Mode use Assign Selected, Select Points and Remove from Bone. Auto Skin gives points their nearest bone. Export refuses patch points with no bone. Joint limits and IK chains are below. Delete or re-parent bones in the rig's Edit Mode.
  1. Connections lists the rings where limbs attach. Use Create for Limb, Rename, Delete and, in Edit Mode, Add Stub Socket. For the active ring set the Parent and Child classes, host bone (Set / Default) and corners (Pick Ring / From Selection). Optimise Start and All Rings pick the best starting corner for combining.

Playing a clip

  1. Choose Load Animation > walk.
  2. Press Space or scrub the timeline.
  3. To edit keys, press Select Rig and open a Dope Sheet or Action Editor.

Validate: three tiers

Validate (will it load?) checks the creature as Export would write it:

  • Blocking problems (red) stop the Object Editor loading it. EXPORT BLOCKED means Export would refuse; the message says why. If you deleted, merged or duplicated vertices, press Ctrl+Z.
  • STOCK: something every base-game creature has is missing. It still loads.
  • WARN: advice about export, limbs or connections.
  • COMBINE: combining problems, never blocking. Combine Checks: Quick runs test combines; Off only the instant check.
  1. Leave Combine Checks on Quick and press Validate (will it load?).
  2. Read the verdict in the status bar and every line in the Info editor.

Export: untouched means byte-identical

  1. Press Export Model, or use File > Export > Impossible Creatures Creature (.sgm). Save somewhere of your own and keep the stock files.
  1. Read the report. It lists what changed; an untouched creature comes out identical to its source.
  • You may overwrite the creature's own source file, except after adding, deleting, re-parenting or renaming bones, or creating a stub bone. Then use another name.
  • Export refuses broken control points, object transforms, shape keys, extra modifiers, a deleted rig or skin image, a source file changed since import, and unsupported skeleton edits. The message gives the fix.

Combine Preview

Open the Combine Preview sub-panel. It combines your creature, unsaved edits included, with another one.

  1. Choose This Creature Is the Torso or This Creature Donates Parts.
  2. Choose the other creature: Stock, Object (in this scene) or File.
  3. Toggle the parts: Head, Tail, Front Legs, Rear Legs, Wings, Front Arms.
  4. Press Preview. A ghost appears with its stats and warnings; press Refresh after edits. Clear removes it, Materialize… saves it as a creature and imports it, and Validate Combines runs the quick checks.

Bake Textured Mesh

To render in Eevee or Cycles, press Bake Textured Mesh. It makes a textured copy, Rhinoceros_baked. Posed (redo panel) bakes the current pose. Editing the copy does not change the creature.

  • Keep the creature at the origin with no transform, modifiers or shape keys.
  • Never delete, merge, duplicate or sort vertices with Blender's mesh tools. Undo if you do.
  • A saved .blend can still export only while the source .sgm stays where it was.
  • Eevee and Cycles need Bake Textured Mesh or Evaluated Surface.
  • A creature's .ebp (motion tree, events) cannot be generated or edited.
  • Combine Preview shows no animations.
  • Only Linux is tested. Treat Windows and macOS as unverified.
