Gatherers, characters, structures and props

Anything that isn't a combiner animal is a scene object: henchmen, characters, buildings, scenery. Its .sgm holds mesh parts, usually with a skeleton and clips. Its .ebp blueprint sits beside it.

Starting a project

The game can't load a scene object built from nothing, so you start from a copy.

  1. Use File > New > Impossible Creatures Project..., or New Impossible Creatures Project in the IC tab.
  2. Set Type to Gatherer / character or Structure / prop.
  3. In Start from, pick a stock model or Another .sgm file.... If no stock models are listed, set the Game folder in the add-on's preferences, or set IC_INSTALL and restart Blender.
  4. Set Animations to Keep its own or None.
  5. Choose a folder of your own and a file name, and confirm. The model and blueprint are copied there and opened.

Opening one

  1. Use File > Import > Impossible Creatures Model (.sgm / .ebp), or Import Model in the IC tab.
  2. Keep Clips as Actions on to edit animations.
  3. If textures are reported missing, set the Game folder.

What you are looking at

  • One mesh object per part, at full detail, with the game's textures.
  • A <name>_rig armature if there is a skeleton, with vertex groups named after its bones.
  • Clips as Actions: use Load Animation and Select Rig.
  • In the IC tab: model info, the rig box, export buttons and the Blueprint panel.

Editing the mesh

Edit a part in Edit Mode with any mesh tool. These are exported:

  • moved, added or deleted geometry, including extrude and subdivide;
  • UVs, seams and flat shading;
  • bone weights (an unweighted vertex goes to the root bone);
  • moving faces to another of the model's own materials.

Warnings:

  • Join new pieces into a part (Ctrl+J). Separate objects aren't exported.
  • Don't delete a part object: its original shape is exported.
  • Moving, rotating or scaling a part in Object Mode isn't exported.
  • Material and texture changes aren't saved; export warns you. The skeleton can't be changed: export stops until you undo bone changes.

Exporting

  1. Press Export Scene Object (.sgm) for geometry and clips (needs a rig), or Export Scene Geometry (.sgm) for geometry only.
  2. Keep Let the engine rebuild the detail ladder on.
  3. Only changed parts are rebuilt. Read the report and any warnings.
  • A part holds at most 12,288 vertices, counted after splitting at UV seams and flat faces. If refused, reduce detail (for example with a Decimate modifier, applied).
  • Editing a part with damage states is refused unless you tick Drop the damage states of edited parts, which removes them.
  • This writes only the .sgm. For a folder with the blueprint too, use Export Entity Folder (next chapter).
