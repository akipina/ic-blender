The Blueprint panel

A scene object's .ebp blueprint sets its kind, name, footprint, offset and sounds. The Blueprint panel in the IC tab appears when the model's part, rig or group empty is active.

Loading the blueprint

  1. Select the model and press Load Blueprint. The status box lists your edits; Reset discards them.
  2. If there is no .ebp, press Start a New Blueprint. A new one has no motion tree or events, so the game won't play the model's animations.

What the panel shows

BoxWhat to set
NameThe in-game name, up to 255 letters. Codes like $41545 come from the language files.
Kind of thingKind and Class number: what the game makes of the model.
Footprint and offsetX, Z: path cells a building blocks (buildings only; 2 game units each; 0 and 0 measures the model). Offset moves the model on its footprint (Y raises it).
SoundsSounds to preload, one per line, like DATA:AUDIO\SPECIALFX\STRUCTURES\WOODBIND.PAT. Missing files are skipped silently.
Where the game finds itThe folder under Data/art/ebps/. Check it if the panel calls it a guess.

Gameplay numbers (read only) shows speed, health, cost and so on. A thing with a new name gets its kind's default numbers.

Export Entity Folder

  1. Press Export Entity Folder.... Set File name and Folder in the game.
  2. Choose an empty folder of your own. Game and Steam folders are refused.
  3. Press Export Entity Folder. It writes the .sgm and .ebp under Data/art/ebps/, and a README.txt.
  • Edited parts with damage states need Drop the damage states of edited parts ticked.
  • Textures and the stats file aren't included.

Trying it in the game

  1. Use a copy of the game that you own, never the Steam folder.
  2. Merge the exported Data folder into that copy's main folder. Loose files override packed ones.
  3. Start the game. To undo, delete the two files. If something is missing, check warnings.log.
  • A new name appears only where a map or script asks for it.
  • To replace a stock thing, export under its exact folder and name.

In multiplayer, every player needs the same files.
